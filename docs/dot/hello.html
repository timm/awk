Hello, dot

Smallest working dot program: running mean of one column.

The file

Save as hello.awk in dot/. Twelve lines.

# hello.awk -- running mean of column 1

function num_init(it) { .it.n = 0; .it.mu = 0; return it }

function num_add(it, x) {
  .it.n++
  .it.mu += (x - .it.mu) / .it.n }

BEGIN { N = new("num") }

      { num_add(N, $1) }

END   { printf "n=%d mean=%.3f\n", .N.n, .N.mu }

Step 1: see the rewrite

$ dot hello.awk
function num_init(it) { HEAP[it]["n"] = 0; HEAP[it]["mu"] = 0; return it }

function num_add(it, x) {
  HEAP[it]["n"]++
  HEAP[it]["mu"] += (x - HEAP[it]["mu"]) / HEAP[it]["n"] }

BEGIN { N = new("num") }

      { num_add(N, $1) }

END   { printf "n=%d mean=%.3f\n", HEAP[N]["n"], HEAP[N]["mu"] }

Two rules at work:

  • .it.n → HEAP[it]["n"] (value-char dot field)
  • .N → HEAP[N] (bare dot object ref)

Step 2: run it

$ printf "1\n2\n3\n4\n5\n" \
  | gawk -f <(dot dot.awk) -f <(dot hello.awk)
n=5 mean=3.000

What just happened

  1. new("num") — allocates ID 1, sets .it.is = "num", calls num_init to seed slots.
  2. Each input row: num_add(N, $1) updates running mean (Welford's algorithm).
  3. END reads .N.n and .N.mu — same as HEAP[N]["n"], HEAP[N]["mu"].

Limitation seen here

If you ran dot hello.awk above, the comment # hello.awk became # hello["awk"]. The preprocessor rewrites inside comments and strings — it's regex, not a parser. Harmless when piped into gawk (comments are ignored), ugly when shown to humans. More limitations.
