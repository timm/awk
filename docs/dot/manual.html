Manual

The preprocessor, runtime, types, and conventions.

Preprocessor

Two rewrites applied to source before gawk sees it. A "value-char" is anything in [A-Za-z0-9_])]. So it.x rewrites; .x at line start does not.

Source
.it.cols
.d.rows[r][i]
.d
new(.d.ykind)
After prep
it["cols"]
d["rows"][r][i]
HEAP[d]
new(HEAP[d]["ykind"])

Run the preprocessor manually with dot file.awk or make show.

new

Allocate an object, dispatch its initializer. new(t) increments NID, sets .it.is = t, and calls t_init if defined. Returns the new ID.

function new(t,    it, fn) {
  it = ++NID;  .it.is = t
  fn = t "_init"
  return (fn in FUNCTAB) ? @fn(it) : it }

Storage lives in HEAP[id]["field"].

out / free

Lifetime helpers. out(i, x) deletes every HEAP[j] with j > i and returns scalar x. Unsafe if a survivor still references a freed ID.

free(i) drops one slot precisely. Safer.

function spread(d, rows,    y, v) {
  y = ycol(d, rows); v = var(y); free(y); return v }

arr

Force a value to be an array. gawk creates arrays-of-arrays lazily. arr(x) is the standard idiom.

function arr(x) { x[""] = 0; delete x[""] }

Polymorphic dispatch

Each object carries its type string in .it.is. A polymorphic call builds the function name and uses gawk's indirect call.

function add(k, x, train,  fn) {
  fn = .k.is "_add"
  return @fn(k, x, train) }

Dispatchers in numsym.awk: add, like, mid, var. Add your own by following the pattern.

num

Numeric column. Welford running mean + variance with optional weight. w=1 adds, w=-1 subtracts (used by the active learner to evict rows).

function num_add(it, x, train, w,    d, d2) {
  w = (w == "" ? 1 : w + 0)
  if (x == "?") return x
  x += 0
  if (!train) return x
  if (w < 0 && .it.n <= 2) { .it.n=0; .it.mu=0; .it.m2=0; return x }
  .it.n  += w
  d  = x - .it.mu;  .it.mu += w * d / .it.n
  d2 = x - .it.mu;  .it.m2 += w * d * d2
  return x }

function num_var(it) {
  return .it.n < 2 ? 0 : sqrt(.it.m2 / (.it.n - 1)) }

function num_mid(it) { return .it.mu }

sym

Symbolic column. Counts table, mode, entropy. Optional weight for sub.

function sym_init(it)   { arr(.it.has); return it }

function sym_add(it, x, train, w) {
  w = (w == "" ? 1 : w + 0)
  if (x == "?" || !train) return x
  .it.n      += w
  .it.has[x] += w
  if (.it.has[x] <= 0) delete .it.has[x]
  return x }

function sym_var(it,    e, k, p) {
  for (k in .it.has) { p = .it.has[k]/.it.n; e -= p*log(p) }
  return e }

function sym_mid(it,    k, b, bv) {
  bv = -1
  for (k in .it.has) if (.it.has[k] > bv) { bv = .it.has[k]; b = k }
  return b }

Polymorphic dispatcher in numsym.awk:

function add(k, x, train, w,  fn) {
  fn = .k.is "_add"
  return @fn(k, x, train, w) }

Conventions

  • UPPER = global. HEAP, NID, FUNCTAB.
  • lowercase = local. Declare in the gawk pseudo-arg slot (extra spaces in arg list).
  • Every object sets .it.is to its type string.
  • Run rogues() at END to flag any lowercase name leaked into SYMTAB.
  • BEGIN/END blocks have no local scope — move logic to functions if you need locals there.

rogues

End-of-run leak detector.

function rogues(    i) {
  for (i in SYMTAB)
    if (i ~ /^[a-z]/) print "leak:", i > "/dev/stderr" }

Limitations

Read these before deploying to anything you care about.

  • Preprocessor is regex, not a parser. A literal ".x" inside a string or regex constant gets rewritten too. So does printf "%.3f" if a value-char precedes the dot. Workarounds: rename the field, or write raw HEAP[x] directly.
  • Comments are not stripped. A .x inside a # ... comment also rewrites. Harmless but ugly in make show.
  • .it.is is a reserved field name. Used internally for type dispatch. Don't shadow it.
  • out(i, x) is unsafe when any object past slot i is still referenced. Returned references become dangling. Use free(i) for precise drops.
  • Monotonic IDs. NID never decreases. Long-running processes accumulate slots. No GC, no recycling.
  • No type checking. add(num_obj, "abc", 1) coerces silently per awk rules.
  • Indirect call cost. Every polymorphic add() does string concat + FUNCTAB lookup per row. Hot loops can call num_add directly.
  • gawk 5.4.0 bug: gensub's second match returns empty captures. The preprocessor uses a match/substr loop instead.
  • Bash 4+ required. macOS /bin/sh is bash 3.x — process substitution <(...) won't work there.
