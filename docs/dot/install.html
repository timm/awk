Install

Two requirements: gawk and bash.

Requirements

ToolVersionWhy
gawk≥ 4.xindirect calls (@fn), FUNCTAB, SYMTAB
bash≥ 4.xprocess substitution <(...)
makeanydemo targets

Note on gawk 5.4.0: the preprocessor avoids gensub(...,"g") due to a bug where the second match's captures come back empty. A match/substr loop is used instead.

macOS

brew install gawk

Default /bin/sh on macOS is bash 3.x — too old for <(...). Run from bash or zsh, not sh.

Linux

sudo apt install gawk    # debian/ubuntu
sudo dnf install gawk    # fedora

Clone & run

git clone https://github.com/timm/awk
cd awk/dot
make stats DATA=path/to/data.csv

The dot wrapper resolves its own location, so once it's on PATH it works from any directory:

export PATH=$PWD:$PATH
dot dot.awk     # print rewritten file

Dev shell

From repo root:

make sh

Launches an interactive bash with etc/bash.rc sourced — aliases, prompt with branch indicator, and ~/.local/bin on PATH.
