Tour

Zero to running a polymorphic gawk program. Real prompts, real output, copy-pastable.

1

Install gawk

$ brew install gawk        # macOS
$ sudo apt install gawk    # debian/ubuntu
2

Clone the repo

$ git clone https://github.com/timm/awk
$ cd awk/dot
$ ls
dot          dot.awk    hello.awk   Makefile
numsym.awk   prep.awk   stats.awk
$ export PATH=$PWD:$PATH
3

Write a one-line dot program

No objects yet — just the preprocessor's two rules:

$ cat > tour1.awk <<'EOF'
BEGIN { .me.name = "tim"; .me.job = "prof"
        print .me.name, .me.job }
EOF
4

See what dot rewrites it to

$ dot tour1.awk
BEGIN { HEAP[me]["name"] = "tim"; HEAP[me]["job"] = "prof"
        print HEAP[me]["name"], HEAP[me]["job"] }

Two rules: .me.name → HEAP[me]["name"]; bare .me → HEAP[me].

5

Pipe the rewrite into gawk

$ gawk -f <(dot tour1.awk)
tim prof
6

Add a polymorphic object

A running mean using new() from dot.awk:

$ cat > tour2.awk <<'EOF'
function num_init(it)   { .it.n=0; .it.mu=0; return it }
function num_add(it, x) { .it.n++; .it.mu += (x - .it.mu)/.it.n }

BEGIN { N = new("num") }
      { num_add(N, $1) }
END   { printf "n=%d mean=%.2f\n", .N.n, .N.mu }
EOF
$ printf "10\n20\n30\n40\n50\n" \
  | gawk -f <(dot dot.awk) -f <(dot tour2.awk)
n=5 mean=30.00

What happened: new("num") allocated ID 1, set .it.is="num", called num_init. Each row called num_add. END printed .N.n and .N.mu.

7

Use the bundled NUM/SYM types

numsym.awk defines num + sym types and the polymorphic dispatchers add, like, mid, var. stats.awk uses them to compute per-column stats on a CSV:

$ head -2 ~/gits/moot/classify/heart.c.csv
AGE,sex,cp,TRESTBPS,CHOL,fbs,...,num!
63,male,typ_angina,145,233,t,...,<50
$ make stats DATA=~/gits/moot/classify/heart.c.csv
column                      n          mid       spread
AGE                       303       54.366        9.082
sex                       303         male        0.624
cp                        303       asympt        1.206
TRESTBPS                  303      131.624       17.538
CHOL                      303      246.264       51.831
...

UPPERCASE columns are numeric (mean / stdev). Lowercase columns are symbolic (mode / entropy). Same add() call dispatches to the right type via .it.is.
