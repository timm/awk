Object sugar for gawk.

dot is one preprocessor and a 23-line runtime. Pipe any source through dot and gawk sees normal awk. Build polymorphic types in awk without writing HEAP[it]["field"] a hundred times.

  • Tiny. 10-line preprocessor, 23-line runtime, 61-line NUM/SYM types.
  • One rule. A leading dot means object access. .it.n → HEAP[it]["n"].
  • Polymorphic. add(it, x) dispatches to num_add or sym_add via .it.is.

Syntax sample

A leading dot means object access. .it.n → HEAP[it]["n"]; bare .x → HEAP[x].

Plain gawk

function num_add(it, x,    d, d2) {
  HEAP[it]["n"]++
  d  = x - HEAP[it]["mu"]
  HEAP[it]["mu"] += d / HEAP[it]["n"]
  d2 = x - HEAP[it]["mu"]
  HEAP[it]["m2"] += d * d2 }

dot

function num_add(it, x,    d, d2) {
  .it.n++
  d  = x - .it.mu
  .it.mu += d / .it.n
  d2 = x - .it.mu
  .it.m2 += d * d2 }
