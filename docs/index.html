Tiny gawk tools.

A small family of gawk tools, layered. Each is one preprocessor pass + a few hundred lines. Each does one thing. Each can be read in a sitting.

dot

Object sugar for gawk. .it.field → HEAP[it]["field"]. Preprocessor + runtime + NUM/SYM stats.

Tour · Example · Manual

dotlearn

ML on top of dot. Three apps: tree, naive Bayes, active learning. On auto93, ~14% labels → top-tier picks.
